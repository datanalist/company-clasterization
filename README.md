# Система кластеризации компаний по новостным данным

Данная система предназначена для автоматического объединения компаний в кластеры на основе новостных данных. Система анализирует новостные источники, выявляет упоминания компаний и группирует их по контекстуальной близости.

## Архитектура системы

- **Frontend:** Streamlit
- **Backend:** FastAPI
- **База данных:** SQLite
- **Модели машинного обучения:** Sentence Transformers, UMAP, HDBSCAN

## Функциональность

- Автоматическое объединение компаний в кластеры на основе новостных данных
- Присваивание каждому кластеру информативного названия
- Возможность выбора периода новостного охвата (день, неделя, месяц или произвольный период)
- Визуализация кластеров компаний
- Система пользователей с биллингом (кредитная система)

## Установка и запуск

### Предварительные требования

- Python 3.8+
- Pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте следующие переменные:

```
SECRET_KEY=your_secret_key
TELEGRAM_API_ID=your_telegram_api_id
TELEGRAM_API_HASH=your_telegram_api_hash
TELEGRAM_PHONE=your_telegram_phone
TELEGRAM_USERNAME=your_telegram_username
```

### Запуск backend (FastAPI)

```bash
cd src
uvicorn app:app --reload
```

### Запуск frontend (Streamlit)

```bash
cd src/frontend
streamlit run app.py
```

## Использование системы

1. Зарегистрируйтесь в системе или войдите в существующий аккаунт
2. Выберите период для анализа новостей
3. Запустите процесс кластеризации
4. Дождитесь завершения процесса
5. Просмотрите результаты кластеризации и визуализацию

## Дополнительная информация

Система использует следующие ML-компоненты:
- **Sentence Transformers** для создания эмбеддингов текста
- **UMAP** для снижения размерности
- **HDBSCAN** для кластеризации
- **KeyBERT** для генерации информативных названий кластеров
