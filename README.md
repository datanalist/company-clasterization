# Company-clastering
Кластеризация компаний по новостям


```

├───data                <- Каталог со всеми данными
│   ├───external        <- Данные с "внешних" сервисов
│   ├───interim         <- Данные с "внутренних" сервисов
│   ├───processed       <- Конечные обработанные данные
│   └───raw             <- Исходные данные
├───docs                <- Документация
├───notebooks           <- Ноутбуки ipynb с экспериментами
├───src                 <- Основной код сервиса
│   └───data            <- Пакеты работы с данными
```
