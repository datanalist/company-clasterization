# Техническое задание на разметку данных

## Входные данные:
Новостные сообщения в текстовом формате.

## Цель
Разметить названия компаний/брендов/франшиз.
Разметить главный(-ые) субъекты - названия компаний/брендов/франшиз, о которых идет речь в новости.

## Уточнения:

- Разметка производится с помощью ПО "Label-studio" и экспортируется в формате JSON-MIN
- Каждое новостное сообщение размечается 2-мя метками
- Первая метка - "Brand", указывает, что слово является именем бренда.
- Вторая метка - "Main", указывает, что слово является именем главного субъекта.
- Главный субъект должен иметь сразу обе метки
- Если наименования встречаются в нескольких формах, то необходимо выделить все словоформы
- Размеченное слово не должно содержать лишних символов (точки, кавычки, запятиые, пробелы)
- Размечаются только бренды, выступающие в роли компаний (названия программ, акций и прочее не размечается)
- Брендами являются так же коммерческие спортивные организации ("Зенит", "UFC" и проч.)
- Брендами являются так же некоммерческие организации


## Пример c разметкой находится в [label-example.json](https://drive.google.com/file/d/1XUb-K4N0cqlxx84le48caAw3a3q1SqQU/view?usp=sharing)

## Порядок установки ПО "Label-Studio":

1. Установка через pip:
   ```solaris
   pip install label-studio
   ```

2. Запуск Label-Studio:
   ```
   label-studio start
   ```

3. После запуска откройте веб-браузер и перейдите по адресу:
   ```
   http://localhost:8080
   ```

4. Создайте новый аккаунт или войдите в систему.

5. Создайте новый проект:
   - Нажмите "Create Project"
   - Укажите название проекта
   - Выберите тип разметки "Named Entity Recognition"
   - Загрузите данные для разметки
   - Настройте метки "Brand" и "Main"

6. Импортируйте текстовый датасет из файла `text.txt`, его вы найдете по ссылке:
[text.txt](https://drive.google.com/file/d/1E6858YXP6CbAqtygQbqkf7oqISBD3aZR/view?usp=drive_link)

7. Начните разметку, следуя инструкциям выше.
